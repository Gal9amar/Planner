# FinitiOnline — אפיון עסקי

> גרסה 1.0 · אוגוסט 2026

## 1. הבעיה

סל קניות זהה יכול לעלות **25%-40% יותר** בין רשת לרשת ואפילו בין סניפים של אותה
רשת. הצרכן הישראלי לא באמת יכול להשוות: באתרי הרשתות רואים רק את המחירים של אותה
רשת, אפליקציות ההשוואה הקיימות מציגות מוצרים בודדים ולא סל שלם, וחלקן מבוססות על
נתונים חלקיים או ישנים.

## 2. ההזדמנות הרגולטורית

**חוק המזון (2014)** מחייב כל קמעונאי מזון גדול לפרסם באינטרנט, בפורמט מכונה-קריא,
את **כל המחירים בכל סניף** — ולעדכן אותם תוך שעה משינוי. זה מקור נתונים רשמי, חוקי,
מלא ועדכני, שרוב הצרכנים כלל לא יודעים על קיומו, כי הוא מפורסם כקבצי XML גולמיים
שאינם שמישים לאדם רגיל.

FinitiOnline הופכת את הקבצים האלה לחנות השוואה שימושית.

## 3. מה המערכת עושה

| יכולת | ערך לצרכן |
|---|---|
| **קטלוג מאוחד** מ-13 רשתות | חיפוש אחד במקום 13 אתרים |
| **טעינה לפי עיר** — בוחרים ערים, המערכת מורידה רק אותן | דיסק ותעבורה מינימליים, נתונים שרלוונטיים לי |
| **השוואת מחיר פר מוצר** בכל סניף שמוכר אותו | לראות מיד איפה הכי זול ומה הפער |
| **"איפה הסל הזה הכי זול?"** — דירוג סניפים לסל שלם | ההחלטה האמיתית היא על סל, לא על מוצר |
| **סינון מרובה** — כמה ערים, רשתות וסניפים יחד | השוואה רק בין חנויות שרלוונטיות לי |
| **חיפוש סלחני** — "מסטיקים בטעמים" מוצא "מסטיק בטעם" | לא צריך לנחש את הניסוח המדויק של הרשת |
| **מדבקת "חיסכון %"** על פערים של 25%+ | לזהות מוצרים ששווה לקנות במקום אחר |
| **שמירת רשימות והיסטוריית הזמנות** | רשימת הקניות השבועית נטענת בלחיצה |
| **רענון בלחיצת כפתור** | הנתונים תמיד בני פחות מיום |

## 4. קהלי יעד

1. **משקי בית מודעי-מחיר** — הקהל הרחב; חיסכון של מאות שקלים בחודש על סל שבועי.
2. **משפחות עם רשימה קבועה** — שמירת רשימה + השוואה חוזרת = ערך מיידי חוזר.
3. **מפתחים/אנליסטים** — ה-API הפתוח והמסד המקומי הם תשתית למחקרי מחירים.

## 5. בידול מול קיים

| | FinitiOnline | אפליקציות השוואה קיימות |
|---|---|---|
| מקור נתונים | הקבצים הרשמיים, ישירות מהרשתות | לרוב גירוד אתרים / נתונים חלקיים |
| השוואת סל שלם | ✔ דירוג סניפים מלא כולל חוסרים | לרוב מוצר-מוצר |
| פרטיות | הכל רץ מקומית, אפס שרתים חיצוניים | חשבון + נתונים בענן |
| עלות תפעול | ~אפס (אין שרתים, אין רישיונות) | תשתית ענן + צוות |
| שקיפות | קוד פתוח בגובה העיניים | קופסה סגורה |

## 6. מצב נוכחי (אוגוסט 2026)

- 6 רשתות חיות ומאומתות: שופרסל, רמי לוי, אושר עד, יוחננוף, טיב טעם, קשת טעמים
- מודל **city-first**: מתחילים ריק, טוענים רק את הערים שנבחרו (עיר ≈ 35MB, דקות בודדות)
- חנות web מלאה (RTL, מובייל, dark mode) + API מתועד, כולל חיפוש סלחני בעברית
- רענון אינקרמנטלי של מה שטעון: ~2–3 דקות

## 9. מודל הפעלה

כיום: כלי מקומי-אישי (self-hosted) ללא עלות תפעול. אפשרויות עתידיות אם יוחלט
להפוך למוצר: אתר ציבורי (דורש אירוח + תזמון רענון), מודל freemium על התראות
והיסטוריה, או API בתשלום לאנליסטים — כולן מחוץ לתכולה הנוכחית.
