# FinitiOnline — רשימת קניות משותפת

רשימת הקניות של המשרד. מקלידים מוצר, קובעים כמות, מסמנים מה נקנה, והרשימה נשלחת במייל
למי שעושה את הקנייה. בלי מחירים, בלי קטלוג, בלי שליפת נתונים חיצוניים.

יושבת בתוך Planner (`WorkGant/finitionline/`) כתהליך Node נפרד על פורט **3040**,
ומוגשת בכתובת `https://planner.dolcemaster.co.il/finitionline/`.

## הרצה מקומית

```bash
cd WorkGant/finitionline
cp env.example .env        # ולערוך: FINITIONLINE_ADMIN_EMAIL, OTP_DEBUG=1 לפיתוח
node server.js             # → http://127.0.0.1:3040/finitionline/
```

התלויות (express, better-sqlite3, dotenv) נפתרות מ-`../node_modules` של Planner. אין צורך ב-`npm install` נפרד.
עם `OTP_DEBUG=1` קוד ההתחברות מודפס לקונסול, כך שאפשר להתחבר גם בלי SMTP.

## מי משתמש

- **עובדים** — אין התחברות. העמוד פתוח לכל מי שברשת הפנימית של החברה. לחיצה על 👤 שומרת שם (בדפדפן בלבד) שמופיע ליד מוצרים שהוספת.
- **מנהל יחיד** — המייל קבוע ב-`.env`. כניסה דרך "כניסת מנהל" בתחתית העמוד בקוד חד-פעמי למייל. רק מנהל מחובר רואה את ⚙ הגדרות (נמענים, שם, לוגו), "שלח עכשיו" ו"נקה הכל".

## מה המערכת עושה

| יכולת | פרטים |
|---|---|
| מסך במבנה חנות | קטלוג כרטיסים של כל מוצר שהוזמן אי פעם, עם "הוסף לרשימה" וכמות; עגלה דביקה בצד = הרשימה המשותפת |
| רשימה משותפת | כולם רואים את אותה רשימה; הדפדפן פולל גרסה כל 5 שניות |
| הוספה מהירה | חיפוש בקטלוג; Enter מוסיף; מוצר שלא קיים נוסף כחדש ונכנס לקטלוג; שם קיים מעלה כמות |
| סימון "נקנה" | ☐ / ☑ לכל פריט, עם "נקה נקנו" |
| סגירה ושליחה | שומר להיסטוריה, שולח ב-SMTP הפנימי (dc1), מרוקן |
| שליחה שבועית | כל יום שלישי 08:00 שעון ישראל, אוטומטית, בלי לרוקן |
| היסטוריה | שליחה חוזרת, טעינה חזרה לרשימה, מחיקה |
