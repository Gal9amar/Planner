ארכיטקטורה — Planner

מבנה כולל

Planner בנוי משני שכבות ברורות: Express backend (server.js, auth.js, db.js, logger.js) ו-frontend stateless שמורכב מ-index.html (shell), workgant-sidebar.js (IIFE משותף), ושלושה SPAs (annual.html, monthly.html, sprint.html). אין build step, אין module bundler — הכל HTML + Vanilla JS + React via Babel Standalone מה-CDN.

index.html — ה-Shell

index.html מגדיר את הפריסה הויזואלית הקבועה: sidebar בימין (#wg-sidebar-root) וא-area ראשי בשמאל עם שלושה ילדים אפשריים:

  • gantt-welcome — מסך ברוכים הבאים, מוצג כשאין גאנט פתוח
  • gantt-frame — <iframe> שטוען את annual/monthly/sprint.html עם פרמטר ?ganttId=N
  • wg-profile-screen — מסך פרופיל/ניהול משתמשים (מוחבא, מוחלף עם ה-iframe)

ה-modal ליצירת גאנט ושינוי שם מוגדר ב-index.html. הסיידבר קורא ל-window._wgsb_newGantt(catId) שמפעיל את הלוגיקה שם.

workgant-sidebar.js — ה-IIFE המשותף

workgant-sidebar.js הוא IIFE גדול (2175 שורות) הנטען ב-index.html. הוא אחראי לכל הסיידבר, login modal, profile screen, וניהול משתמשים.

window.wgAuth Bridge

הסיידבר חושף window.wgAuth = { authFetch, getUser }. ה-SPAs בתוך ה-iframe מגיעים אל זה דרך window.parent.wgAuth (או window.top.wgAuth) כדי לשלוח בקשות API מאומתות. כך session יחיד תקף לכל ה-SPAs בלי שכל iframe ינהל token בנפרד. 

// בתוך annual.html / monthly.html / sprint.html
const authFetch = window.parent?.wgAuth?.authFetch || fetch;

_wgsb global

הסיידבר מייצא window._wgsb עם פונקציות ציבוריות: reload(), logout(), openProfile(), closeProfileScreen(), loadBackups() וכו'. index.html מחבר callbacks: window._wgsb_newCat, window._wgsb_newGantt וכד'.

שמירה היא delete + re-insert בתוך transaction. כל save של tasks מוחק את כל ה-tasks של הגאנט ומכניס מחדש לפי sort_order. לכן אין update פר-שורה — כל השינויים נשמרים יחד.

session expiry handling

authFetch() בודק אם response הוא 401 — ואם כן קורא ל-clearSession() + showLoginModal(). ה-iframe מאזין לאירוע זה דרך window.parent: אחרי login מחדש, הסיידבר קורא ל-frame.contentWindow.__wgOnLogin() כדי להחזיר את ה-SPA לפעולה ללא reload.

Static File Serving

server.js מגיש static files מהתיקייה הראשית בלבד: app.use('/', express.static(path.join(__dirname))). לכן כל קובץ HTML, JS, CSS ב-WorkGant/ נגיש ישירות. תיקיית docs/ גם היא נגישה ב-https://planner.dolcemaster.co.il/docs/.

Frontend Architecture: "Shared But Duplicated"

שלושת ה-SPAs (annual/monthly/sprint) חולקים מבנה זהה: React reducer, tabs menu, פונקציות load/save, export to Excel, manpower, sprints. אך הקוד מועתק ומותאם בכל קובץ — אין shared module. זה מחייב זהירות: שינוי פונקציה בקובץ אחד לא מתפשט לאחרים.

ראה gantt-types-comparison.html לפרטים על ההבדלים.
