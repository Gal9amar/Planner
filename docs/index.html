Planner — תיעוד מפתח

v2.1.1 Node.js + Express React 18 (Babel Standalone) SQLite production: planner.dolcemaster.co.il · port 3020

Planner (שם קודם: WorkGant) הוא כלי ניהול גאנטים פנימי לצוות QA/פיתוח. Backend: Node.js + Express + SQLite (better-sqlite3). Frontend: שלושה קבצי HTML עצמאיים (annual.html, monthly.html, sprint.html) — כל אחד SPA מלא ב-React 18 + Babel Standalone, ללא bundler.
Auth: OTP בלבד (אין סיסמה). index.html הוא ה-shell: sidebar + iframe שטוען את אחד משלושת ה-SPAs.
שם: שם התצוגה שונה ל-"Planner" ב-2026-05-05; URL paths, CSS classes וקוד פנימי עדיין משתמשים ב-workgant.

מסמכים

  • 🏛️ architecture.html — ארכיטקטורה index/iframe/sidebar data flow, window.wgAuth bridge, אופן טעינת SPAs, auth token lifecycle, כניסה חדשה אחרי session expiry
  • 🗄️ data-model.html — מודל נתונים SQLite Schema מלא ברמת עמודה לכל 14 טבלאות, JSON fields מפורטים, apiStateToAppState / stateToPayload, gotcha task_number + checklist מניעה
  • 🔐 auth-and-permissions.html — Auth ו-הרשאות OTP flow מקצה לקצה, JWT, היררכיית roles (superadmin→admin→editor→viewer), clampToAdminPerms, נעילת חשבונות, user_all_access
  • 📊 gantt-types-comparison.html — השוואת סוגי גאנטים Annual vs Monthly vs Sprint: שדות ייחודיים, חישובי שעות, reducer actions, ייצוא Excel, הבדלי UI — ה-shared-but-duplicated pattern
  • 📡 api-reference.html — API Reference כל endpoint עם method, auth נדרש, request body, response, הערות — categories, gantts, teams, backups, test-runs, auth routes
  • 🚀 deployment-and-ops.html — Deployment ו-Operations PM2, nginx, cron backup, SSH access, bump גרסה, .env, smtp-config.json, restart process
  • ⚠️ known-issues-and-gotchas.html — בעיות ידועות באג task_number (2026-07-23) בפירוט מלא, סיכוני כפילות קוד בין קבצי גאנט, מגבלות email clients, gotchas נוספים
