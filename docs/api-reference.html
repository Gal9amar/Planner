API Reference — Planner

כל endpoints מוחזרים כ-JSON. base URL: https://planner.dolcemaster.co.il/api (ב-dev: http://localhost:3020/api).

Auth: Header Authorization: Bearer <token>. SSE endpoints תומכים גם ב-?token=<jwt>.

Auth Routes — /api/auth/*

EndpointMethodAuthתיאורRequestResponse
/auth/otp/request POST ציבורי שלח קוד OTP. תמיד מחזיר ok:true (לא חושף קיום מייל) { email } { ok: true }
/auth/otp/verify POST ציבורי אמת קוד → JWT { email, code } { token, user: { id, email, role } }
/auth/login POST ציבורי התחברות עם email+password (legacy — נשמר לתאימות פנימית בלבד, ראה auth.js:522). המערכת בפועל OTP-only; endpoint זה לא בשימוש בזרימת הלוגין הרגילה { email, password } { token, user: { id, email, role } }
/auth/logout POST ציבורי logout (client מוחק token) — { ok: true }
/auth/me GET viewer+ פרטי המשתמש הנוכחי — { id, email, role }
/auth/me PATCH admin+ עדכון email/password עצמי (admin בלי currentPassword) { email?, password? } { ok, token, user }
/auth/change-password POST viewer+ שינוי סיסמה עצמי (requires currentPassword) { currentPassword, newPassword } { ok: true }
/auth/users GET admin+ רשימת משתמשים (admin — רק שיצר; superadmin — הכל) — מערך users עם gantt_ids, category_ids, all_access, created_by_email
/auth/users POST admin+ יצירת משתמש + שליחת welcome email { email, role, gantt_ids?, category_ids?, all_access? } { ok: true, id }
/auth/users/:id PATCH admin+ עדכון email/role/is_active/password/permissions { email?, role?, is_active?, password?, gantt_ids?, category_ids?, all_access? } { ok: true }
/auth/users/:id DELETE admin+ מחיקת משתמש (admin — רק שיצר; לא ניתן למחוק עצמך) — { ok: true }
/auth/users/:id/resend-welcome POST admin+ שלח מחדש welcome email (עם temp password) — { ok: true }
/auth/locked-accounts GET superadmin רשימת חשבונות נעולים + remaining_minutes — מערך locked rows
/auth/locked-accounts/:id DELETE superadmin שחרור נעילה מיידית — { ok: true }
/auth/email/test POST superadmin שלח מייל בדיקה SMTP { to } { ok: true }
/auth/email/preview POST superadmin שלח תבנית welcome/otp לתצוגה מקדימה { to?, type: 'welcome'/'otp'/'both' } { ok, sent_to, type }
/auth/logs/dates GET superadmin רשימת תאריכים שיש להם log files — מערך YYYY-MM-DD strings
/auth/logs GET superadmin לוג יום ספציפי, עם סינון ?date=&user=&action=&gantt_id= query params מערך log entries
/auth/logs/stream GET superadmin SSE — real-time logs של היום — text/event-stream

Categories — /api/categories

EndpointMethodAuthתיאורRequestResponse
/categories GET viewer+ כל הקטגוריות + גאנטים (מסונן לפי הרשאה) — [{ id, name, type, gantts: [...] }]
/categories POST admin+ יצירת קטגוריה. מוסיפה אוטומטית הרשאת קטגוריה לכל בעלי all_access { name, type: 'annual'/'monthly'/'sprint' } { id, name, type, gantts: [] }
/categories/reorder POST admin+ עדכון sort_order לרשימת קטגוריות { order: [{ id, sort_order }] } { ok: true }
/categories/:id PATCH admin+ שינוי שם קטגוריה { name } category object
/categories/:id DELETE admin+ soft delete (רק אם ריקה מגאנטים פעילים) — { ok: true } או 400 אם יש גאנטים

Gantts — /api/gantts

EndpointMethodAuthתיאורRequestResponse
/gantts/:id GET viewer+ state מלא של גאנט (requires hasGanttAccess) — { ...gantt, roles, employees, tasks, sprints(+items) }
/gantts POST editor+ יצירת גאנט. editor — רק בקטגוריות מורשות. auto-permission לעורך/admin { category_id, name, type, year?, month? } gantt object
/gantts/:id PATCH editor+ שינוי שם גאנט (requires hasGanttAccess) { name } gantt object
/gantts/:id/state PATCH editor+ שמירת state מלא — DELETE + INSERT per entity type בתוך transaction { gantt?, roles?, employees?, tasks?, sprints? } { ok: true }
/gantts/:id DELETE admin+ soft delete + cascade hard delete של entities. editor — 403. — { ok: true }
/annual-gantts/all-with-tasks GET viewer+ כל גאנטים שנתיים + שמות המשימות (ללא סינון הרשאות — לצורך ייבוא) — [{ id, name, category_name, tasks: [{id, task_name}] }]
