PM2 — פקודות נפוצות

# restart (שינוי קוד)
sudo /usr/lib/node_modules/pm2/bin/pm2 restart planner

# logs
sudo /usr/lib/node_modules/pm2/bin/pm2 logs planner --lines 50

# status
sudo /usr/lib/node_modules/pm2/bin/pm2 list

# שמירת config (אחרי שינוי טופולוגיה)
sudo /usr/lib/node_modules/pm2/bin/pm2 save --force

אל תריץ pm2 כ-gal — יוצר PM2 daemon שני שמתחרה על port 3020 וגורם crash loops. תמיד sudo pm2 .... ראה CLAUDE.md של qa-board לפרטים.

ALLOWED_ORIGINS=https://planner.dolcemaster.co.il

Nginx Configuration

Nginx מוגדר כ-reverse proxy. קובץ config: /etc/nginx/sites-enabled/planner.dolcemaster.co.il.conf (הנחה — לבדוק בשרת). location / → proxy_pass http://localhost:3020.

Backup

Cron Job

גיבויים נשמרים ב-backups/planner/ (תת-תיקייה בפרויקט). ניהול דרך UI: טאב "גיבויים" בפרופיל superadmin. ה-API מציג את הקבצים, מאפשר מחיקה ושחזור.

שחזור גיבוי: db.close() → fs.copyFileSync → process.exit(0). PM2 מאתחל אוטומטית לאחר exit(0).

SSH backup ישיר

# העתק DB מהשרת לוקאלית
scp user@phptest1:/var/www/planner.dolcemaster.co.il/data/workgant.db ./backup-$(date +%Y%m%d).db

DB לא ב-git — data/workgant.db ב-.gitignore. לעולם לא לעלות DB לgit (מכיל passwords, emails של משתמשים אמיתיים).

גרסה (Version Bump)

  1. ערוך package.json → שדה version
  2. Push + pull בשרת
  3. sudo pm2 restart planner
  4. הגרסה נטענת ב-startup ומוחזרת מ-GET /api/version
  5. version-check.js מציג badge בסיידבר כשגרסה חדשה זמינה

Logs

logger.js כותב JSON NDJSON ל-logs/YYYY-MM-DD.log. Cleanup אוטומטי: מחיקת קבצים מעל 30 יום (startup + כל 6 שעות). SSE stream ל-superadmin בזמן אמת: GET /api/auth/logs/stream.

Superadmin Seed

ב-db.js: אם אין משתמשים, נוצר superadmin ב-seed: gal@finitione.com. בנוסף, יש שורה שמבטיחה שמייל זה תמיד superadmin גם אם role שונה ב-DB: 

db.prepare(`UPDATE users SET role='superadmin' WHERE email='gal@finitione.com' COLLATE NOCASE`).run();

seed password נמצא ב-db.js ב-plain text (hash בלבד, אך ה-plain password גלוי בקוד). לשנות מייד בייצור דרך UI.
